Як Python приймає рішення?

до цеху python

Теоретичний матеріал

У цьому розділі ти дізнаєшся, як комп'ютер приймає рішення і чи може він думати. Познайомишся з операторами порівняння. Навчишся використовувати логічні оператори та умовні конструкції if, else, elif, та створювати власні програми, які виконують різні дії в залежності від умови.

Як Python приймає рішення?

У повсякденному житті ми постійно приймаємо рішення.

Наприклад:

  • Якщо надворі йде дощ — беремо парасольку.
  • Якщо світлофор зелений — переходимо дорогу.
  • Якщо завтра контрольна робота — готуємося до неї.
  • Якщо день народження друга — вітаємо його.

І комп'ютер також може приймати рішення але він робить це зовсім не так, як людина. Людина може сумніватися. Комп'ютер — ніколи. Для нього існують лише дві відповіді: ТАК або НІ. У Python вони назвиваються відповідно 'True' та 'False'.

Уявіть собі, що потрібно написати програму яка визначає:

  • Чи є число парним?
  • Чи є число додатнім?
  • Чи є у слові літера 'a'?

Як комп'ютер зрозуміє, що відповісти? Він для цього повинен перевірити умову. Саме з цього починається програмування майже всіх сучасних програм, ігор та сайтів. І саме цьому ми сьогодні навчимося.

Що таке математична логіка?

Математична логіка — це наука про правильні міркування та правила прийняття рішень.

Для комп'ютера будь-яке рішення будується дуже просто. Спочатку перевіряється умова. Потім вибирається одна з двох відповідей (ТАК або НІ). А щоб це реалізувати у програмуванні, потрібно створити логічний вираз.

Логічний вираз — це запитання, на яке можна відповісти лише: ТАК або НІ (True або False). Наприклад: 5 більше за 3 ⭢ ТАК (True), 5 менше за 3 ⭢ НІ (False). Або: 5 дорівнює 5 ⭢ ТАК (True), 5 не дорівнює 5 ⭢ НІ (False).

У Python ці запитання записуються спеціальними символами (комбінацією символів), які називають операторами порівняння. Вони дозволяють порівнювати два значення та визначати, чи виконується певна умова. Результатом порівняння завжди буде значення True або False.


Оператори порівняння:


Оператор Назва Приклад Результат
> Більше 5 > 3 True
>= Більше або дорівнює 5 >= 5 True
< Менше 5 < 3 False
<= Менше або дорівнює 5 <= 5 True
== Дорівнює 5 == 5 True
!= Не дорівнює 5 != 3 True

Запам'ятайте! У програмуванні мовою Python оператор "=" та операор "==" - це різні оператори. Оператор "=" використовується для присвоєння значення змінній, а оператор "==" використовується для порівняння двох значень.


Приклади

1. Найпростіша арифметична операція. 

print(8 + 5)         # отримаємо результат: >>> 13

2. Можна також додавати змінні. 

a = 12
b = 7
print(a + b)         # отримаємо результат: >>> 19

3. Віднімання відбувається таким самим чином, як і додавання і розглянемо його на прикладі розв'язання задачі: "У бібліотеці було 12 книг. 7 книг віддали в іншу бібліотеку. Скільки книг залишилося у бібліотеці?" 

books = 12
books_out = 7
print(books - books_out)         # отримаємо результат: >>> 5

4. У Python множення записується символом *, а не ×. Задача: В одній коробкці міститься 24 цукерки. Яка кількість цукерок міститься у 5 тких коробках. 

boxes = 5
candies_box = 24
print(boxes * candies_per_box)         # отримаємо результат: >>> 120

5. Для ділення використовується символ /. Задача: В одній коробкці міститься 24 цукерки. Їх розділили порівну між 6 учнями. Яку кількість цукерок отримав кожен учень? 

students = 6
candies = 24
print(candies / students)         # отримаємо результат: >>> 4.0

Зверніть увагу! Оператор / завжди повертає дробове число (float), навіть якщо ділення виконується без остачі і обидва числа мають тип int().

6. Іноді нас цікавить лише кількість цілих частин. Для цього існує оператор // - цілочислове ділення. Цей оператор працює наступним чином: він виконує звичайне ділення і відсікає (відкидає) дробову частину. Тобто результатом ділення націло буде ціле число типу int(). Розглянемо роботу оператора розв'язавши задачу: У класі 28 учнів. За одну парту сідають двоє. Скільки повністю зайнятих парт буде? 

students = 28
print(students // 2)         # отримаємо результат: >>> 14

А якщо учнів у класі 29?

students = 29
print(students // 2)         # отримаємо також результат: >>> 14

7. Остача від ділення націло - це одна з найцікавіших операцій Python. Вона позначається символом % і використовується для визначення парності чисел, або чи ділиться націло одне число на інше і тому подібне.

Розглянемо як працює дана операція. 

print(14 % 3)         # отримаємо результат: >>> 2

Пояснення: 14 розділити на 3 можна таким чином: 14 = 4 + 4 + 4 + 2. Остача від ділення націло дорівнює 2. Або 25 розділити на 5 можна таким чином: 25 = 5 + 5 + 5 + 5 + 5 + 0. Остача від ділення націло дорівнює 0.

8. Піднесення до степеня у математиці записують 5², а у Python використовують оператор **. Розглянемо приклад: 

print(5 ** 2)         # отримаємо результат: >>> 25
print(2 ** 5)         # отримаємо результат: >>> 32

Дану операцію використовують при знаходженні площі квадрата, об'єму куба та інших геометричних фігур.

Давайте обчислимо об'єм куба зі стороною 5 см. Для цього потрібно піднести число 5 до степеня 3. В даній задачі я використаю дві змінні: edge_length - в якій буде значнення довжини ребра куба, та volume - в якій буде значення об'єму куба. 

edge_length = 5
volume = edge_length ** 3
print(volume, 'см³')         # отримаємо результат: >>> 125 см³

Зверніть увагу! Щоб отримати квадратний корінь числа потрібно піднести це число до степеня 0.5 

number = 25
sqrt = number ** 0.5
print(sqrt)         # отримаємо результат: >>> 5.0
