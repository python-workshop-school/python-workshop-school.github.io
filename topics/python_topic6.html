На роздоріжжі. Оператори вибору варіанту match ... case.

до цеху python

Теоретичний матеріал

У попередній темі ми навчилися використовувати оператор розгалуження if, щоб програма могла приймати рішення залежно від виконання певної умови. Але іноді потрібно перевірити одне значення на відповідність кільком можливим варіантам.

Наприклад:

  • якщо користувач ввів 1 — виконати одну дію;
  • якщо 2 — іншу;
  • якщо 3 — ще одну;
  • для будь-якого іншого значення — повідомити про помилку.

Для таких ситуацій у Python можна використати конструкцію match ... case, про яку ти дізнаєшся опрацювавши матеріал цього розділу.

Як Python приймає рішення?

У повсякденному житті ми постійно приймаємо рішення.

Наприклад:

  • Якщо надворі йде дощ — беремо парасольку.
  • Якщо світлофор зелений — переходимо дорогу.
  • Якщо завтра контрольна робота — готуємося до неї.
  • Якщо день народження друга — вітаємо його.

І комп'ютер також може приймати рішення але він робить це зовсім не так, як людина. Людина може сумніватися. Комп'ютер — ніколи. Для нього існують лише дві відповіді: ТАК або НІ. У Python вони назвиваються відповідно 'True' та 'False'.

Уявіть собі, що потрібно написати програму яка визначає:

  • Чи є число парним?
  • Чи є число додатнім?
  • Чи є у слові літера 'a'?

Як комп'ютер зрозуміє, що відповісти? Він для цього повинен перевірити умову. Саме з цього починається програмування майже всіх сучасних програм, ігор та сайтів. І саме цьому ми сьогодні навчимося.

Що таке математична логіка?

Математична логіка — це наука про правильні міркування та правила прийняття рішень.

Для комп'ютера будь-яке рішення будується дуже просто. Спочатку перевіряється умова. Потім вибирається одна з двох відповідей (ТАК або НІ). А щоб це реалізувати у програмуванні, потрібно створити логічний вираз.

Логічний вираз — це запитання, на яке можна відповісти лише: ТАК або НІ (True або False). Наприклад: 5 більше за 3 ⭢ ТАК (True), 5 менше за 3 ⭢ НІ (False). Або: 5 дорівнює 5 ⭢ ТАК (True), 5 не дорівнює 5 ⭢ НІ (False).

У Python ці запитання записуються спеціальними символами (комбінацією символів), які називають операторами порівняння. Вони дозволяють порівнювати два значення та визначати, чи виконується певна умова. Результатом порівняння завжди буде значення True або False.


Оператори порівняння:


Оператор Назва Приклад Результат
> Більше 5 > 3 True
>= Більше або дорівнює 5 >= 5 True
<< /td> Менше 5 < 3 False
<=< /td> Менше або дорівнює 5 <= 5 True
== Дорівнює 5 == 5 True
!= Не дорівнює 5 != 3 True

Запам'ятайте! У програмуванні мовою Python оператор "=" та оператор "==" - це різні оператори. Оператор "=" використовується для присвоєння значення змінній, а оператор "==" використовується для порівняння двох значень.

Подивимося, що відбувається, якщо Python порівнює числа. 

print(8 > 3)            # отримаємо результат: >>> True
print(5 < 2)            # отримаємо результат: >>> False
print(10 == 10)         # отримаємо результат: >>> True
print(15 != 15)         # отримаємо результат: >>> False

Цікаво! Python нічого не пояснює. Він просто повідомляє: Так або Ні тобто True або False. Практично всі сучасні мови програмування використовують саме два логічні значення: True та False.

Як же Python приймає рішення?

Для реалізації такої поведінку у Python використовують оператор if його ще називають оператором розгалуження. Він має три форми: if - неповне розгалуження, if-else - повне розгалуження, if-elif-else - множинне розгалуження. Кожна з них дозволяє виконувати різні дії в залежності від умови. Розглянемо кожну з них на прикладах нижче.

Уявіть ситуацію. Учень отримав оцінку. Якщо оцінка дорівнює 12, учитель каже: "Відмінна робота!". Якщо ні - нічого не говорить.

Синтаксис 

'Неопвна форма'
if умова:
    команда

'Повна форма'
if умова:
    команда1
else:
    команда2

'Множинна форма'
if умова1:
    команда1
elif умова2:
    команда2
else:
    команда3

Зверніть увагу. Після умови ставиться : (двокрапка) і обов'язково робиться відступ (4 пробіли або клавіша Tab) перед командою, яка виконується, якщо умова істина, хибна або невизначена. Саме відступ показує Python, що ця команда належить до оператора if, else або elif.


Приклади

1. Перевіримо доступу до сайту для повнолітніх.

Уявіть ситуацію, коли користувач вводить свій вік. Якщо йому 18 років або більше, то він отримує доступ до сайту. Якщо ні - доступ заборонено. 

age = 18

if age >= 18:
    print("Доступ дозволено.")    # >>> Доступ дозволено.

В даному прикладі ми використали неповну форму розгалуження if. Якщо умова істинна, то виконується команда print("Доступ дозволено."). Якщо ж умова хибна, то команда не виконується і нічого не відбувається.

2. Перевіримо стан погоди. 

temperature = -5

if temperature < 0:
    print("На вулиці мороз.")
else:
    print("На вулиці тепло.")

У даному прикладі ми використали повну форму розгалуження if-else. Якщо умова істинна, то виконується команда print("На вулиці мороз."). Якщо ж умова хибна, то виконується команда print("На вулиці тепло.").

3. Визначимо рівень навчальних досягнень учня

Іноді потрібно перевірити не одну, а кілька умов. Наприклад, визначити рівень навчальних досягнень учня за кількістю отриманих балів з навчального предмету. У такому випадку використовують оператор elif який означає означає інакше-якщо. 

score = 10

if score >=10 and score <=12:
    print("Високий рівень!")
elif score >=7 and score <=9:
    print("Достатній рівень!")
elif score >=4 and score <=6:
    print("Середній рівень!")
else:
    print("Початковий рівень!")

Запам'ятайте! Python перевіряє умови зверху вниз. Якщо перша умова істинна, то інші умови не перевіряються. Тобто якщо score = 10, то буде виведено "Високий рівень!" і перевірка інших умов не відбудеться.

4. Отримаємо доступ до сайту.

Іноді всередині одного if потрібно ще раз перевірити умову. Такі конструкції називають вкладеними розгалуженнями. 

age = 16
has_ticket = True

if age >= 14:
    if has_ticket:
        print("Вхід дозволено.")

Зверніть увагу! Якщо хоча б одна умова буде хибною то повідомлення не з'явиться. Вкладені розгалуження дозволяють створювати більш складні умови та логіку прийняття рішень у програмі. Але не варто зловживати вкладеними розгалуженнями, оскільки це може ускладнити читання та розуміння коду.


Практична робота

Мета: Дослідити роботу умовного оператора if в Python.

Завдання 1: Пенсіонер.

  • Запитайте у користувача його вік.
  • Якщо йому виповнилося 65 років або більше, виведіть повідомлення: "Пенсіонер".

Завдання 2: Додатне чи від'ємне число.

  • Запитайте у користувача число.
  • Якщо число додатне, виведіть повідомлення: "Число додатне".
  • Якщо число від'ємне, виведіть повідомлення: "Число від'ємне".
  • Якщо число дорівнює нулю, виведіть повідомлення: "Число дорівнює нулю".

Завдання 3: Парне чи непарне число.

  • Запитайте ціле число.
  • Якщо число парне, виведіть повідомлення: "Число парне".
  • Якщо число непарне, виведіть повідомлення: "Число непарне".

Завдання 4: Перевірка пароля.

  • Створіть змінну password та присвойте їй значення пароля. Наприклад: password = "python".
  • Запитайте у користувача введений пароль.
  • Якщо введений пароль співпадає зі значенням змінної password, виведіть повідомлення: "Пароль вірний".
  • Якщо ні, виведіть повідомлення: "Пароль невірний".

Завдання 5: Знижка.

  • Користувач вводить суму покупки.
  • Якщо вона більша за 1000 грн, повідомте: "Ви отримуєте знижку 10%".
  • Якщо ні, виведіть повідомлення: "Сума покупки для отримання знижки недостатня".

Завдання 6: Світлофор.

  • Користувач вводить колір світлофора (всі назви кольорів вводимо малими літерами).
  • Якщо колір зелений, виведіть повідомлення: "Переходьте".
  • Якщо колір жовтий, виведіть повідомлення: "Готуйтесь".
  • Якщо колір червоний, виведіть повідомлення: "Зупинітся".

Завдання 7: Мініпроєкт «Контроль доступу».

  • Запитайте ім'я користувача.
  • Запитайте пароль.
  • Якщо якщо пароль дорівнює '12345' - виведіть повідомлення: "Вітаємо, <ім'я>!".
  • Якщо ні - виведіть повідомлення: "Доступ заборонено!".



Завдання

Початковий рівень

1. Введіть число. Якщо воно більше 100, виведіть: "Велике число". В іншому випадку виведіть: "Звичайне число".
2. Запитайте температуру. Якщо температура нижча за 10°, повідомте: "На вулиці холодно".


Середній рівень

1. Запитайте число. Якщо воно кратне 5, повідомте про це.
2. Запитайте пароль. Правильний пароль: 'school'. Якщо паролі співпадають, виведіть повідомлення: "Пароль правильний". Якщо ні, виведіть повідомлення: "Пароль невірний".


Достатній рівень

1. Введіть два числа. Виведіть більше з них.
2. Введіть три цілі числа - сторони трикутника. Перевірте чи існує такий трикутник. Умова існування трикутника: сума довжин будь-яких двох сторін має бути більшою за довжину третьої сторони.


Високий рівень

1. Створіть програму перевірки входу. Користувач вводить: логін та пароль. Правильні дані: Логін: admin, пароль: 12345. Якщо дані співпадають, виведіть: Вхід виконано. Інакше: Помилка входу.
2. Створіть програму перевірки віку. Якщо користувачу виповнилося 16 років або більше, повідомте: "Можна отримати паспорт". Інакше: "Ще зарано".
