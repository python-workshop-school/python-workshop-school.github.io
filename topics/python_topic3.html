Тема 3

Введення даних - функція input().

до цеху python

Теоретичний матеріал

У цьому розділі ти дізнаєшся, як організувати інтерактивний діалог програми з користувачем: як зчитувати значення з клавіатури, присвоювати їх змінним та приводити отримані дані до потрібного типу, та навчися створювати прості діалогові програми.

Для чого потрібна функція input()

До цього часу всі значення у програмах були записані самим програмістом.

Наприклад: 

name = "John Silver"
age = 25

Але якщо програмою користуватиметься інша людина, то як забезпечити їй можливість вводити власні дані? Саме для цього використовується функція input(). Вона дозволяє зчитувати дані, які користувач вводить з клавіатури. При роботі програми дана функція зупиняє її виконання, і чекає доки користувач не введе необхідні дані та не натисне клавішу Enter. Після чого введене значення надається змінній у вигляді текстового рядка і робота програми продовжується.

Дана функція має необов'язковий парамет - текстову підказку, яка вказується в дужках функції і являє собою текстовий рядок в одинарних чи подвійних лапках. Зазвичай таку підказку використовують, щоб не помилитися якого типу дані потрібно ввести.

Наприклад: 

name = input("Введіть своє ім'я: ") 
print(name)

# >>> Введіть своє їм'я: Зіновій
# >>> Зіновій

Як працює функція input()

  • Програма на екрані відображає повідомлення для введення даних.
  • Користувач вводить дані у вигляді тексту.
  • По закінченню введення натискає клавішу Enter.
  • Функція input() повертає введене значення у вигляді рядка (тип str).
  • Введене значення записується у змінну за допомогою оператора присвоєння (=).

Зверніть увагу, що функція input() завжди повертає рядок (тип str), навіть якщо користувач вводить число. Тому, якщо потрібно працювати з числами, необхідно виконати явне перетворення типу.

Що ж робити коли нам потрібно ввести не текстові, а дані інших типів?

Для вирішення цієї проблеми в Python існують функції перетворення типів: int(), float(), str(), bool(). Вони дозволяють перетворювати рядки у числа, числа у рядки та виконувати інші перетворення.

Наприклад, щоб у змінній зберегти ціле число, потрібно використати функцію явного перетворення типу int(): 

age_str = input("Введіть ваш вік: ")  # Число 25 - це рядок "25"
age = int(age_str)  # Тепер це ціле число 25

Або ж записати всю конструкцію одним рядком: 

age = int(input("Введіть ваш вік: ")) # Тут у змінну age буде збережено ціле число, а не рядок.

Якщо ж нам потрібно зберегти дійсне число, то використовується функція float(): 

weight_str = input("Введіть вашу вагу: ")  # Число 70.5 - це рядок "70.5"
weight = float(weight_str)  # Тепер це дійсне число 70.5

Або ж записати всю конструкцію одним рядком: 

weight = float(input("Введіть вашу вагу: ")) # Тут у змінну weight буде збережено дійсне число, а не рядок.

Зверніть увагу, таким самим чином можна перетворювати цілі числа в дійсні і навпаки, а також перетворювати числа в рядки використовуючи функцію str().

Зверніть увагу, що якщо користувач введе нечислове значення (наприклад, текст), то при спробі перетворення рядка у число, Python видасть помилку тексту програми ValueError. Тому завжди потрібно уважно слідкувати та перевіряти введені дані перед перетворенням.


Приклади

1. Створимо просте привітання.

Код програми 

name = input("Як тебе звати? ")
print("Привіт,", name) # отримаємо результат:

#>>> Як тебе звати? Солоха
#>>> Привіт, Солоха

2. А в цьому прикладі додамо трішки математики, визначимо який буде ваш вік через сім років.

Код програми 

age = int(input("Скільки вам років? "))
print("Через сім років вам буде", age + 7, "років.")

#>>> Скільки вам років? 15
#>>> Через сім років вам буде 20 років.

Типові помилки

  • Використання функції input без дужок, наприклад: 
    age = input # - це помилка;
age = input() # - правильно.
  • Неправильне перетворення. 
    age = input() # - якщо ви введете "десять", то виникне помилка значення:
>>> ValueError: invalid literal for int(): 'десять', яка вказує на те, що використовується невірний тип даних.
  • Знаходження суми рядків замість суми чисел. 
    a = input("Введіть число а: ") # наприклад введемо 17
b = input("Введіть число b: ") # наприклад введемо 25

print(a + b) # отримаємо результат
>>> 1725
    • Як бачите, збою програми не має, і вона успішно завершує роботу і навіть виводить результат, ось тільки він не вірний. І такі помилки найскладніше знаходити. Як має бути правильно: 
    a = int(input("Введіть число а: ")) # використовуємо функцію перетворення рядка в ціле число int()
b = float(input("Введіть число b: ")) # а тут використовуємо функцію перетворення рядка в ціле число float()

print(a + b) # отримаємо результат
>>> 42.0
