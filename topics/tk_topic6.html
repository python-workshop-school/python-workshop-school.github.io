Тема 6

Клас Entry()

до цеху tkinter

Теоретичний матеріал

Віджет Entry – клас, який використовується для створення однорядних полів вводу у графічному інтерфейсі. Поля вводу дозволяють користувачам вводити текстові дані у вікно програми. Віджет Entry може бути налаштований за допомогою різних параметрів для зміни його зовнішнього вигляду та поведінки.

Загальний синтаксис:

name = Entry(window, options)

де, name – ім'я поля вводу, window – ім'я вікна, на якому розташовується поле, options – параметри поля.

Властивості Entry:


Властивість Значення
width Ширина поля вводу в пікселях. Якщо не вказано, ширина буде розтягуватися по ширині текстового напису.
background (bg) Колір фону поля вводу.
foreground (fg) Колір тексту в полі вводу.
borderwidth (bd) Ширина рамки поля вводу в пікселях. За замовчуванням дорівнює 2.
state Стан поля вводу. Може мати значення: "normal" або "disabled".
justify Вирівнювання тексту в полі вводу. Може мати значення: "left", "right", "center".
relief Стиль поля вводу. Може мати значення: "flat", "raised", "sunken", "groove", "ridge".
overrelief Стиль рамки поля вводу при наведенні на нього. Може бути "flat", "raised", "sunken", "groove", "ridge".
font Шрифт тексту в полі вводу. Може бути заданий як кортеж (назва_шрифту, розмір, стиль) або як рядок з назвою шрифту.
textvariable Змінна, яка зберігає текст, що відображається в полі вводу.
show Символ, який буде відображатися замість введеного тексту. Використовується для створення полів вводу паролів.
validate Визначає, коли повинна виконуватися перевірка введених даних. Може мати значення: "focus", "focusin", "focusout", "key", "all".
validatecommand Функція, яка буде викликана для перевірки введених даних. Параметри цієї функції залежать від значення властивості validate.
invalidcommand Функція, яка буде викликана, якщо перевірка введених даних не пройшла успішно.
cursor Вказує тип курсора, який буде відображатися при наведенні на поле вводу. Може мати значення: "arrow", "hand2", "cross", "ibeam" та інші.

Функції Entry:

Властивості та функції Entry дозволяють працювати з текстом, який міститься у віджеті. З текстового поля можна "взяти" текст за допомогою функції get(). У текстове поле можна вставити текст методом insert(). Також можна видалити текст методом delete().


Функція Значення
get() Повертає текст, який міститься у полі вводу.
insert() Вставляє текст у поле вводу на вказану позицію.
delete() Видаляє текст із поля вводу.

Приклад

Створимо вікно, яке міститиме такі компоненти: мітку з текстом "Введіть ваше ім'я", пусте однорядкове текстове поле, кнопку з надписом "Згенерувати" та пусту мітку в кінці. Для кнопки реалізуйте дію: щоб після натиснення на кнопку в пусту мітку записується текст: "Вітаю, {ім'я}".

Код програми 

from tkinter import *  
def f():
	label_data['text'] = f"Вітаю, {entry_name.get()}"
	label_data.configure(justify=CENTER)
root = Tk()
root.title("Entry")
root.config(bg="#333333")
name = Label(root, text="Введіть Ваше ім'я: ", font="Arial 13", bg="#333333", fg="white",justify=CENTER).pack()
entry_name = Entry(root, font="Arial 13", justify=CENTER)
entry_name.pack(pady=10)
button_get = Button(root, text="Згенерувати", font="Arial 13", bg="#FF8C00", command=f)    
button_get.pack()
label_data = Label(root, font="Arial 13", bg="#333333",fg="#FF8C00")             
label_data.pack(side=LEFT, pady=10)
root.mainloop()
