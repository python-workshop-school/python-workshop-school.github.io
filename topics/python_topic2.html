Теоретичний матеріал

У цьому розділі ти дізнаєшся як програма на Python обробляє дані; що таке змінна та які вимоги існують до імен змінних; для чого існують різні типи даних у Python та як їх перетворювати з одного виду в інший.

Будь-яка комп'ютерна програма обробляє дані. В інформатиці ці дані називають величинами. Величини можуть бути різних типів: числа, текст, логічні значення (істина або хибність), списки, словники та інші.

Для зберігання величин у програмі використовують змінні. Змінна - це посилання (адреса) на область пам'яті, в якій зберігається значення цієї величини. Кожній змінній надають ім'я, яке використовується для доступу до її значення.

Правила створення імен змінних (ідентифікаторів) в Python

  • Ім'я змінної повинно починатися з літери або знаку підкреслення (_).
  • Ім'я змінної може містити лише латинські літери (a-z, A-Z), цифри (0-9) та знак підкреслення (_).
  • Ім'я змінної не може починатися з цифри (наприклад, 1step - помилка, а step1 - правильно).
  • Ім'я змінної не може бути зарезервованим ключовим словом мови Python (наприклад: if, for, while, def, class).
  • Імена змінних чутливі до регістру (наприклад, variable і Variable — це різні змінні).
  • Для покращення читабельності імен змінних можна використовувати стиль camelCase (наприклад, myVariableName) або стиль snake_case (наприклад, my_variable_name).
  • Рекомендується використовувати зрозумілі та описові імена змінних, які відображають їх призначення (наприклад, age, name, total_price).

Змінні створюються в момент присвоєння їм значення. Значення змінним надається за допомогою оператора присвоєння (=). Наприклад: 

name = "John Silver"
age = 25

У цьому прикладі створюються дві змінні: name та age. Змінній name присвоюється рядок "John Silver", а змінній age присвоюється число 25. Оскільки мава Python має динамічну типізацію то тип даних автоматично визначається на основі присвоєного значення.

Типи даних

Python має кілька основних типів даних, які використовуються для зберігання і обробки інформації. Ось найпоширеніші типи:

  • int - цілі числа (наприклад, 5, -10, 0)
  • float - числа з плаваючою точкою (наприклад, 3.14, -2.5, 0.0)
  • str - рядки (наприклад, "Привіт, світ!", 'John')
  • bool - логічні значення (True або False)

Для визначення типу даних змінної можна використовувати функцію type(). Наприклад: 

print(type(name))  # <'class 'str''>
print(type(age))   # <'class 'int''>

У мові Python існує два способи перетворення типів даних: явне та неявне. Неявне перетворення відбувається автоматично, коли Python намагається виконати операції між різними типами даних. Наприклад: 

print(5 + 3.14)  # Виведе: 8.14 (неявне перетворення int у float)

Явне перетворення типів здійснюється за допомогою вбудованих функцій: int(), float(), str(), bool(). Наприклад: 

# Конвертація рядка у число (часто потрібна при введенні даних через input())
age_str = "18"
age_num = int(age_str)  # Тепер це число 18

# Конвертація float у int
pi = 3.99
print(int(pi))  # Виведе: 3 (дробова частина просто зрізається!)

# Конвертація числа в рядок
status_code = 200
message = "Код відповіді: " + str(status_code)
print(message)  # Виведе: Код відповіді: 200

# Особливості bool()
print(bool(0))   # Виведе: False
print(bool(5))   # Виведе: True
print(bool(""))  # Виведе: False
print(bool(" ")) # Виведе: True (всередині є пробіл, рядок не порожній)

Важливо: Якщо ви спробуєте конвертувати рядок, який містить літери, у число (наприклад, int("привіт")), Python видасть помилку тексту програми ValueError.

А тепер пропоную розглянути приклади та перейти до практичної частини, яка дозволить максимально ефективно закріпити отримані знання.

Приклади

1. Розглянемо, як Python працює з різними типами чисел одночасно, та як працює ручне відсікання дробової частини.

Код програми 

apples = 5        # Тип: int
weight_per_apple = 0.165  # Тип: float (вага в кг)

# Неявне перетворення: int * float дає float
total_weight = apples * weight_per_apple
print("Загальна вага:", total_weight)  # Виведе: 0.825
print(type(total_weight))              # class 'float'>

# Явне перетворення у int просто відкидає дробову частину
price_per_kg = 45.99
rounded_price = int(price_per_kg)
print("Ціна без копійок:", rounded_price)  # Виведе: 45 (а не 46!)

2. А в цьому прикладі перевіримо, чи користувач взагалі щось ввів. Будь-яке пусте значення автоматично перетворюється на False.

Код програми 

user_input = input("Введіть ваш логін: ")

# Якщо користувач просто натиснув Enter, рядок буде пустим ("")
is_filled = bool(user_input)

print("Користувач ввів дані?", is_filled)

Зверніть увагу в цьому прикладі ми використали функцію input() для отримання даних від користувача, з якою більш детально ознайомимося на наступному занятті.
